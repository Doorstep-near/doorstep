# Web app progress

- Design system: colour/type/shape tokens in `src/styles.css` (light + dark), and the UI kit in `src/components/ui` (buttons, fields, segmented control, cards, status chips, order timeline, amount, copy field, QR, countdown, token picker, sheet/modal, toast, skeleton, empty/error states, banner, explorer link, theme toggle).
- API client (`src/lib/api.ts`) parses every response with the shared zod schemas; the in-browser mock (`src/lib/mock`) implements every route, verifies buyer signatures and is swapped in at one line. Buyer key (`src/lib/buyerKey.ts`) and base58 are tested against RFC 8032.
- Pay flow `/pay/:id`: token picker with live dry quote, per-chain refund address, in-browser buyer key, register + real quote, deposit view (exact amount, network warning, address + QR, countdown, "I've sent it"), live progress polling, quote-expired/incomplete/refunded/failed states, and the "Held safely" success with the order pass.
- Order page `/o/:id` (status headline, timeline, delivery pass QR, "I received it", 6-digit code, complaint window, receipt, details, order-pass import from `#k=`) and confirm page `/confirm/:id` (auto-confirms from `#sig=`, handles bad/duplicate passes).
- Seller app `/seller/*`: token login, responsive shell (sidebar ≥1024 px), dashboard with KPIs, filters, search and table/cards; new-order form with live preview and share sheet (WhatsApp, QR); order detail with one next action per state (ship via Borzo/tracking/hand, confirm by QR scan/paste/code, payout countdown), courier/payout panels and activity log.
- Landing `/` (hero, how it works, trust points, live stats, India COD story, honest trust model), public proof page `/proof/:id` with every on-chain step and NearBlocks links, 404, demo banner and floating demo controls. Typecheck, 69 tests and the production build pass.
- Polish: reviewed every screen in headless Chrome (390 px and 1440 px, light and dark) and fixed what showed up: sticky full-height seller sidebar, compact demo pill on phones, toasts clear of the demo panel, legend spacing, duplicate mobile button, heading role on the confirm error, short-NEAR-account refund validation.
- README rewritten as "do X, see Y" steps (sample data first, then `npm run demo`). Typecheck clean, 70/70 tests pass, production build passes.
